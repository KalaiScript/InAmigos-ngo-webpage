# InAmigos Internship Projects

Welcome to the repository for the InAmigos Internship program. This repository contains the projects and tasks completed during the internship.

## Directory Structure

This repository is organized by tasks:

### [Task 1: Basic Web Development](./Task1)
A static web application with an admin interface, featuring a responsive design and basic HTML/CSS/JS implementation. 
- Features an event management layout
- Professional styling and theming
- Admin dashboard layout

### [Task 3: Neoverse AI Landing Page](./Task3)
A futuristic AI startup landing page built to look like a premium 2035-era product showcase. 
- Built with **Next.js 15, React, TypeScript, and Tailwind CSS v4**
- Features a dark cyberpunk aesthetic, glassmorphism cards, and neon glow effects
- Includes interactive components, a live AI dashboard visualization, and animated counters powered by Framer Motion.

## Getting Started

To explore a specific task, navigate into its respective directory and follow the instructions in its local `README.md` file.

```bash
# Example: Navigating to Task 3
cd Task3
npm run dev
```

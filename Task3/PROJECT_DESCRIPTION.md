# Neoverse AI - The Future of Human-AI Collaboration

Neoverse AI is a futuristic AI startup landing page concept built to look like a premium 2035-era product showcase. The website presents an advanced human-AI collaboration brand through a dark cyberpunk aesthetic, glassmorphism cards, neon glow effects, animated sections, and a bold hero area with interactive call-to-action buttons.

## 🚀 Features

- **Cyberpunk Hero Section**: High-impact animated introduction with futuristic headlines and glowing effects.
- **Glassmorphism UI**: Modern transparent-panel look with backdrop blur and neon borders.
- **Innovation Timeline**: An animated roadmap showing the evolution of AI from 2025 to 2035.
- **Service Showcases**: Interactive cards for AI Personal Assistant, Memory Enhancement, Education, and Healthcare.
- **Live AI Dashboard**: Simulated neural network status visualization for a "live" system feel.
- **Animated Counters**: Dynamic display of metrics like "Neural Connections" and "Sync Accuracy".
- **Chatbot Assistant (NV-1)**: A functional floating chat widget to guide users through the Neoverse.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop experiences.
- **Smooth Animations**: Powered by Framer Motion for a premium, high-tech feel.

## 🛠️ Tech Stack

- **Next.js 15 (React)**: Professional framework for performance and SEO.
- **TypeScript**: Ensuring structural integrity and type safety.
- **Tailwind CSS v4**: Fast, utility-first styling with custom neon theme.
- **Framer Motion**: Advanced scroll-triggered and state-based animations.
- **Lucide React**: Sleek, consistent iconography.
- **Google Fonts**: `Orbitron` for headings and `Poppins` for readable body text.

## 📂 Project Structure

- `src/app`: App Router, global styles, and layout.
- `src/components`: Reusable UI components (Hero, Navbar, Timeline, etc.).
- `src/data`: Static content for services and roadmap milestones.
- `src/lib`: Utility functions and Tailwind merging logic.

## 🔮 Bonus Features Added
- **Neural Network Visualizer**: A simulated real-time processing dashboard.
- **Metrics Dashboard**: Animated statistics demonstrating system performance.
- **Enhanced Chatbot**: Interactive bot with multiple states and fake processing delay.

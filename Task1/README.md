# InAmigos NGO Web Application

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

A modern, responsive, and dynamic web application for the **InAmigos NGO**, designed to spread awareness, showcase community projects, and provide a platform for volunteers and donors to get involved. 

## 🌍 About The Project

InAmigos started with a simple belief: that small acts of kindness can spark massive change. This web application serves as the digital front door for the NGO, featuring:
* Information about the NGO's mission and core values.
* Details on ongoing initiatives (Education, Healthcare, Environment).
* Social impact tracking and gallery showcases.
* A robust "Join Us" form for prospective volunteers and donors.
* An interactive application status tracking system.
* A dedicated Admin Portal for managing requests.

## ✨ Key Features

* **Modern & Responsive UI**: Built with a mobile-first approach ensuring the site looks great on all devices.
* **Dynamic Impact Statistics**: Animated counters showcasing the NGO's reach and impact.
* **Interactive Status Checker**: Allows users who have applied to volunteer or donate to check their application status in real-time.
* **Admin Dashboard**: A secure portal for administrators to review and manage incoming applications.
* **Smooth Scrolling & Animations**: Enhances the user experience with subtle micro-interactions.

## 🛠️ Technologies Used

* **HTML5**: For semantic and accessible page structure.
* **CSS3 (Vanilla)**: For styling, layout (Flexbox/Grid), and responsive design.
* **JavaScript (Vanilla)**: For dynamic functionality, form validation, and DOM manipulation.
* **Font Awesome**: For scalable vector icons.
* **Google Fonts**: Utilizing 'Inter' for clean, modern typography.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You only need a modern web browser to view this project locally.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/KalaiScript/InAmigos-ngo-webpage.git
   ```
2. Navigate to the project directory:
   ```bash
   cd "InAmigos Intern"/Task1
   ```
3. Open `index.html` in your preferred web browser. Alternatively, you can use a local server like Live Server in VS Code for a better development experience.
